## 🛡 零外联 · 零上传（内网可用）

这个版本**不向任何外部服务器发送任何数据**，实测验证过：

| 检查项 | 结果 |
|---|---|
| 页面加载全过程的非本站请求 | **0 个** |
| 所有非 GET/HEAD 请求（上传） | **0 个** |
| `navigator.sendBeacon` | 无 |
| `WebSocket` / `EventSource` | 无 |
| 第三方统计（GA / Sentry / Mixpanel 等） | 无 |
| Cloudflare Turnstile 验证码 | **已移除** |
| 官方 API（`api.pokebonk.com`） | 已剥离，请求全部本地处理 |
| 官方域名校验（0.9.26 新增的防盗版检测） | 已中和 |

**左下角有一个盾牌角标**，显示 `🛡 无外联`。点它可以看到被拦截的外联尝试记录（正常情况下是空的）。

### 三层拦截

```
net-guard.js        拦截 fetch / XHR / sendBeacon / WebSocket / EventSource
                    非本源地址一律拒绝，动态注入的外部 <script>/<link>/<img> 直接移除
        ↓
offline-fetch.js    同源 API 请求（/auth /profile /runs …）全部本地应答，不发网络
        ↓
api-core.js         用 localStorage 当数据库，纯本地逻辑
```

即使游戏代码里藏了外联调用，也会被 `net-guard.js` 挡在发出之前。

## ⚠️ 存档在你的浏览器里 —— 先看这一段

进度存在 `localStorage`，**不上传任何服务器**。

| 情况 | 结果 |
|---|---|
| 正常关浏览器 | ✅ 保留 |
| **清缓存 / 清网站数据** | ❌ **永久丢失** |
| 换浏览器 / 换设备 | ❌ 看不到 |
| 无痕模式 | ❌ 关窗口就没 |
| **对局中途刷新** | ✅ **自动结算保留** |
| 打完一局 | ✅ 自动备份（保留 5 份） |

### 备份方法（三步）

1. 主菜单点右上角 **「存档管理」**
2. 点 **「复制存档」** 或 **「下载文件」**
3. 存到记事本 / 网盘 / 微信收藏

**恢复**：存档管理 → 「粘贴导入」或「导入文件」。

导入前会自动把当前存档备份一份，误操作也能救回来。

## 常见问题

**Q: 我玩了很久，结果清了缓存，能恢复吗？**
如果之前导出过、或没超过 5 局，可以从「存档管理」的自动备份恢复。否则找不回来了。

**Q: 换手机了怎么带走存档？**
旧设备：存档管理 →「下载文件」得到 `.json`。
新设备：存档管理 →「导入文件」选那个 `.json`。

**Q: 为什么有时候图片是空白？**
首次加载要下载约 50 MB 资源，网速慢时会一点点补齐。刷新一次通常就好。

**Q: 对局中不小心关了页面？**
进度会自动结算并保存，重开后星尘和记录都在，但这局不能继续玩。

**Q: 左下角盾牌显示「已拦截 N」怎么办？**
说明有代码尝试外联但被挡住了。点开能看到具体地址，把内容发给我即可。正常情况下应该是 0。

## 技术说明

```
GitHub Pages（纯静态）
├── net-guard.js        网络守卫（最关键，最先加载）
├── api-core.js         浏览器内 API（严格对齐游戏存档 schema）
├── offline-fetch.js    拦截 fetch/XHR，转给 api-core
├── save-manager.js     存档导出/导入/自动备份
├── save-ui.js          「存档管理」面板 + 提醒
└── settle-on-exit.js   刷新前兜底结算
```

构建时对主包做的三处修改：

1. 剥离 `https://api.pokebonk.com` → 请求变同源，被本地拦截
2. 注入 `globalThis.__PB_PATCHED=1; globalThis.__RUN=this`（供调试/面板用）
3. 中和 Cloudflare Turnstile URL + 禁用验证码等待函数 `Yh()`

对入口文件的一处修改：

4. `g=()=>true` —— 绕过 0.9.26 新增的域名白名单（原本只允许 `pokebonk.com` 和内网地址）
