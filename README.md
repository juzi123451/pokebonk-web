## 存档说明（重要）

游戏进度存在你自己浏览器的 `localStorage` 里，**不会上传到任何服务器**。

| 情况 | 结果 |
|---|---|
| 正常关闭浏览器 | ✅ 存档保留 |
| 清理浏览器缓存 / "清除网站数据" | ❌ **存档丢失** |
| 换浏览器 / 换设备 | ❌ 看不到原来进度 |
| 无痕/隐私模式 | ❌ 关掉窗口就没了 |
| 用浏览器设置里的"清除 Cookie 和网站数据" | ❌ 存档丢失 |

### 想长期保存 / 备份

按 `F12` 打开开发者工具 → Console → 粘贴下面这行，回车：

```js
copy(localStorage.getItem('pb.offline.profile'))
```

这样存档就到剪贴板了，存到记事本/网盘。

**恢复存档**：同样打开 Console，粘贴（把 `此处粘贴` 换成你存的字符串）：

```js
localStorage.setItem('pb.offline.profile', 此处粘贴); location.reload();
```

### 定期备份建议

每次玩完重要进度后执行一次 `copy(...)`，养成习惯。清缓存前一定要先备份。

## 技术说明

- 游戏本体来自官方静态资源
- API 请求（认证/档案/对局结算）由浏览器内的 `api-core.js` 应答
- 主包的 API 域名已被替换为同源路径，由 `offline-fetch.js` 拦截
