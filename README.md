# PokéBonk 网页离线版

**直接打开就能玩：** https://juzi123451.github.io/pokebonk-web/

## ⚠️ 存档在你的浏览器里 —— 先看这一段

进度存在 `localStorage`，**不上传任何服务器**。

| 情况 | 结果 |
|---|---|
| 正常关浏览器 | ✅ 保留 |
| **清缓存 / 清网站数据** | ❌ **永久丢失** |
| 换浏览器 / 换设备 | ❌ 看不到 |
| 无痕模式 | ❌ 关窗口就没 |
| **对局中途刷新** | ✅ **自动结算保留** |
| 打完一局 | ✅ 自动备份（保留 5 份） |

### 备份方法（三步）

1. 主菜单点右上角 **「存档管理」**
2. 点 **「复制存档」** 或 **「下载文件」**
3. 存到记事本 / 网盘 / 微信收藏

**恢复**：存档管理 → 「粘贴导入」或「导入文件」→ 选你存的那份。

导入前会自动把当前存档备份一份，误操作也能救回来。

### 自动备份

每打完一局会生成一份快照（最多留 5 份），在「存档管理」面板里可以直接恢复，不用手动导出。

## 常见问题

**Q: 我玩了很久，结果清了缓存，能恢复吗？**
如果你之前导出过或者没超过 5 局，可以从「存档管理」的自动备份恢复。否则找不回来了。

**Q: 换手机了怎么带走存档？**
旧设备：存档管理 →「下载文件」，得到 `.json`。
新设备：存档管理 →「导入文件」，选那个 `.json`。

**Q: 为什么有时候图片是空白？**
首次加载需要下载约 34 MB 资源，网速慢时会一点点补齐。刷新一次通常就好了。

**Q: 对局中不小心关了页面？**
进度会自动结算并保存，重开后星尘和记录都在，但这局不能继续玩。

## 技术说明

```
GitHub Pages（纯静态）
├── api-core.js        浏览器内 API（认证/档案/结算）
├── offline-fetch.js   拦截 fetch/XHR
├── save-manager.js    存档导出导入
├── save-ui.js         存档面板
└── settle-on-exit.js  刷新前兜底结算
```

主包的 API 域名已被替换为同源路径，由 `offline-fetch.js` 拦截并交给 `api-core.js`。
